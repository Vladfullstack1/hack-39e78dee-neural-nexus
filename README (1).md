Официальные файлы базы знаний (`rules.json` и `taxonomy.json`) подключены и находятся в этой папке.

Для пакетного прогона положите датасеты организаторов в `data/`:
- `tickets_train.jsonl.gz`
- `tickets_valid.jsonl`

Внимание: согласно правилам кейса Decentrathon 6.0, исходные датасеты с обращениями игроков (`*.jsonl`, `*.jsonl.gz`) не должны публиковаться в открытом GitHub-репозитории (они добавлены в `.gitignore`).
